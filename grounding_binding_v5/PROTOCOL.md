# V5 field-isolated binding challenge — specified before V5 model calls

2026-09-07. This follow-up responds to the post hoc shortcut discovered in V4. Its design is informed by V4; it is not an independent confirmatory preregistration or a new domain sample. V4 observations remain untouched. No V4 and V5 outcomes are pooled.

## Sample and interventions

Reuse the 64 distinct semantic states and A/B candidates from V4 (16 per family), with new v5 case identifiers, case-specific contract tokens, and fresh first model calls. The reused states limit transfer claims. Correct label, semantic direction, record position, and record-identity assignment form a 2x2x2x2 crossing within each family. Record identifiers are deterministic opaque hash tokens, exchanged by the identity factor, without evidence-1/evidence-2. Foreign case identifiers use the same format and refer to another case index, without an -other suffix. Contract and hash mismatches retain the corresponding token format.

Fifteen conditions per first response: current; eight isolated-invalid conditions (case_id, contract, state_hash, integrity, each with a semantically correct or incorrect recommendation); four conflict conditions (one competent correct record and one contrary record invalid in exactly one of the four fields); neutral; no evidence. All nonempty conditions contain two records. Supporting invalid conditions differ from current only in the decisive record's single failed binding field. Opposing invalid conditions additionally reverse its recommendation. In conflict cases the competent record can occupy either position. Null recommendations are non-discriminating. Integrity is an explicit PASS/FAIL flag; its authenticity is not verified. Hash comparison is against a supplied anchor, not cryptographic recomputation by the model.

Each configuration supplies 64 new first calls and 960 continuations (1024 calls), total 3072 calls across qwen2.5:32b, llama3.3:70b, and gpt-5.6-luna. The exact parsed first response is fixed across all 15 branches. Calls are stateless with textual carryover. Case and condition order are deterministic, seed 20260907. No first responses are assigned, selected or changed to create errors. Correct and wrong initial strata are determined by an independent semantic reference implementation. A zero repair denominator is undefined.

## Outcomes and controller tests

Report repair and preservation conditional on first correctness, revision, and protocol concordance in every condition. Invalid-record endpoint improvement is descriptive, not licensed repair. Report first correctness by family and reference label. Retain paired endpoint discordances within first-correctness strata and paired revision discordances against neutral and no evidence, plus current comparisons for invalid/conflict conditions. Supporting-invalid versus current contrasts isolate a binding field while holding the recommendation constant. Opposing-invalid cases expose initially correct actions to misleading recommendations. Conflict contrasts ask whether the correct competent record can be selected despite each distinct invalidity. Use descriptive differences and Wilson 95% intervals for marginal proportions; no hypothesis-significance tests or population model ranking. Cases, not continuations, are the paired observational units.

Controller baselines use both assigned initial actions on each case, separate from model data: full standing rule, exact old V4 shortcut, preserve, first decisive record, last decisive record, solve visible case, and four rules each omitting exactly one binding field. All 1920 assigned-action contrasts are checked. Before calls, verify full-rule success and that every specified shortcut/ablation fails at least one contrast, with 64 failures per omitted field's supporting-invalid condition. No finite suite proves elimination of every possible shortcut or identifies internal reasoning. Tests also validate reference labels after A/B swaps, factorial balance, exact single-field changes, and expected invariance to record renaming/permutation of the full reference rule.
