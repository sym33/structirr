# Descriptive analysis on observed commitments

This post-collection analysis applies the frozen controller rules to each model's 64 observed first responses and fifteen conditions. It tabulates first-stage accuracy by reference label and task family and reproduces the correction/preservation table from archived continuations. It makes no additional model calls.

Extract `selective_answerability_supplement.zip` alongside this directory to provide `grounding_binding_v5/`. Run `python3 supplementary_analysis/observed_baselines.py` from the submission directory. The original acquisition protocol, analysis files, and frozen supplement remain unchanged.
